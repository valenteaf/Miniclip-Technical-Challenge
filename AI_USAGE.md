# Overall AI usage

I used AI (Cursor, specifically) to create the overall skeleton of the code, as it is a much faster process than writing it all by hand. 

When using AI, it is important for me to have a grasp of what each section of the code (or the code overall) does. I like to create the code sequentially, as I logically think about what to build next. As such, I always create a plan of what to build first, review it, and then ask an agent to build it. 
After a section of code is written by an agent, I go over it, skimming the code, making sure I understand what is being done on a high level.

# Step-by-step process

I started by asking it to build a Python script that would read both localisations .plist files (the older version and the newer one) and store the dictionaries for further analysis.

Then, as I thought of each section to add, I'd either ask an agent to create it for me or, more often than not, I'd use the auto-completion suggestion.

The auto-completion suggestions were often times wrong, and were sometimes rejected altogether, as the AI could not accurectly predict exactly what I was writing, but most of the times they were quite useful and time-saving.

I also asked the AI chatbot for suggestions on how to execute certain Python string or list operations, as I sometimes forget the exact syntax. Most of these were also accepted. However, there were cases were the suggestions were too complex for a simple task, and those were rejected, and I came up of new, simpler ones (sometimes alone, sometimes by speaking with the bot). 

I did not use AI for writing any of the .md files (I apologize for any spelling mistakes). I believe showing the way I think is important, and decided to write everything myself.

Overall, AI saved me quite a bit of time by providing good code auto-completion suggestions, Python documentation and code structure.
