# Overall AI usage

I used AI (Cursor, specifically) to create the overall skeleton of the code, as it is a much faster process than writing it all by hand. 

When using AI, it is important for me to have a grasp of what each section of the code (or the code overall) does. I like to create the code sequentially, as I logically think about what to build next. As such, I always create a plan of what to build first, review it, and then ask an agent to build it. 
After a section of code is written by an agent, I go over it, skimming the code, making sure I understand what is being done on a high level.
